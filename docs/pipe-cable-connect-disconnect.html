Legacy default: meta == 0 MUST be treated as 0x3F (all 6 faces connected) everywhere it is read. Only a wrench toggle makes meta non-zero. Bits 6–7 reserved. opposite face = face ^ 1 (0↔1, 2↔3, 4↔5).
Helper: metaToFaceMask(m) — bit i → FaceMask: META_BIT_TO_FACEMASK[6] = { FACE_EAST, FACE_WEST, FACE_UP, FACE_DOWN, FACE_SOUTH, FACE_NORTH }. Face → world offset: DX[6]={+1,−1,0,0,0,0} DY[6]={0,0,+1,−1,0,0} DZ[6]={0,0,0,0,+1,−1}.
Item ids: pipes 0xF800–0xF803 · cables 0xF400–0xF405 · wrench 0xF005 (ITEM_WRENCH). Detect with ItemId::isPipe(n) / ItemId::isCable(n).
